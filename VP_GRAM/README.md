# Viscous-Plastic and Granular Rheologies 

The present code is used to test different sea ice rheologies with fake random 
data. The code is greatly inspired by the [https://github.com/dringeis/VP_rheologies] project of Damien Ringeisen.
This current project is simplified and has less rheologies. 

The currently implemented rheologies are:

- standard VP (Hibler, 1979)
- Mohr-Coulomb Pure Shear (Tremblay, 1997 and Ringeisen 2026)
- Mohr-Coulomnb Teardrop (Work in progress)
